SKYREALM — ПОДКЛЮЧЕНИЕ НАСТОЯЩЕЙ ПОЧТЫ (ЛОКАЛЬНЫЙ ТЕСТ)
========================================================

ВАЖНО
-----
- Сейчас API работает только на твоём компьютере: http://127.0.0.1:8000.
- Это подключит реальные письма при тестировании на твоём ПК, но НЕ опубликует API в интернете.
- Не присылай пароль приложения в чат и не помещай его в config.js, HTML, app.js или EXE.
- Не раздавай файл server/.env другим людям.

НАСТРОЙКА GMAIL SMTP
--------------------
1. Используй отдельный Gmail-адрес для системных писем SkyRealm, если возможно.
2. В Google Account включи двухэтапную аутентификацию.
3. Открой https://myaccount.google.com/apppasswords и создай пароль приложения. Google требует включённую двухэтапную аутентификацию. Если меню нет, аккаунт может не поддерживать пароли приложений.
4. Скопируй 16-символьный пароль приложения. Это НЕ обычный пароль Gmail. Вставляй его без пробелов.
5. В папке server скопируй .env.example как новый файл с именем .env (именно .env, не .env.txt).
6. Открой server/.env в Блокноте и замени:
   SMTP_USER=your.sender@gmail.com
   SMTP_PASSWORD=replace_with_16_character_google_app_password
   SMTP_FROM=your.sender@gmail.com
   на свой Gmail-адрес и пароль приложения.
7. Оставь:
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_STARTTLS=true
   DEV_PRINT_EMAIL_CODE=false
8. Сохрани .env, перезапусти run_auth_server_dev.bat (если сервер уже открыт, останови Ctrl+C и запусти снова).
9. В лаунчере создай новый тестовый аккаунт с почтой, к которой у тебя есть доступ. Код должен прийти по электронной почте; проверь также «Спам».

ЕСЛИ НУЖНО ВЕРНУТЬСЯ К ЛОКАЛЬНОЙ ПРОВЕРКЕ БЕЗ ПОЧТЫ
---------------------------------------------------
В server/.env установи DEV_PRINT_EMAIL_CODE=true. В этом режиме код печатается в терминале и письмо не отправляется. Не используй этот режим на публичном сервере.

ПОЛЬЗОВАТЕЛИ ИЗ ИНТЕРНЕТА
-------------------------
Чтобы другие игроки получали письма со своих ПК, API нужно разместить на HTTPS-хостинге и использовать постоянную базу данных. Одного запуска на 127.0.0.1 недостаточно. Перед публичным запуском нужно дополнительно настроить безопасность, ограничения запросов, постоянное хранилище и CORS.
