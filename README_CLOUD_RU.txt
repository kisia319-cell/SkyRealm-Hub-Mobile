SKYREALM — ОБЛАЧНЫЙ ЛАУНЧЕР (ОБНОВЛЁННЫЙ ИНТЕРФЕЙС)
=================================================

ЧТО УЖЕ НАСТРОЕНО
-----------------
- Лаунчер использует HTTPS-адрес облачной функции Supabase, а не 127.0.0.1.
- Запросы передают маршрут через параметр ?route=... — это соответствует текущей версии облачной функции.
- В config.js находится только публичный publishable key; секретный ключ в лаунчере не хранится.
- Главные кнопки «Создать аккаунт» переключают форму на регистрацию; отправка формы вызывает реальный облачный API.
- Добавлены подсказки по трём шагам регистрации, раздел FAQ, ссылки на новости и проверку статуса сервера.
- Статус облака проверяется при загрузке, а не просто отображается как всегда онлайн.
- Кнопка «Играть» устанавливает локальный 2D-прототип и запускает его отдельно от лаунчера. Подробности — в README_GAME_RU.txt.
- В архив не включены старые dist/SkyRealm.exe, виртуальные окружения, базы данных, логи и секретный .env, чтобы не запутать сборку и не перенести локальные секреты.

ОБЛАЧНЫЙ API
------------
Проект Supabase: skyrealm-auth-prod
Публичный API: https://jaaguprbfrzrcwuusher.supabase.co/functions/v1/skyrealm-auth
Проверка здоровья: https://jaaguprbfrzrcwuusher.supabase.co/functions/v1/skyrealm-auth?route=%2Fhealth

Проверь в браузере ссылку проверки здоровья. Ожидается JSON с status=ok и service=skyrealm-auth.

КАК ПРОВЕРИТЬ РЕГИСТРАЦИЮ
-------------------------
1. Распакуй архив в новую папку.
2. Открой index.html двойным щелчком. Лаунчер уже настроен на облачный API; запускать server\run_auth_server_dev.bat для облачной версии НЕ нужно.
3. Выбери «Регистрация», укажи имя игрока, почту и пароль от 8 символов.
4. Используй для первого теста адрес, связанный с аккаунтом Resend. Отправитель onboarding@resend.dev — тестовый и не предназначен для рассылки всем игрокам.
5. Введи код из письма в окне лаунчера. Затем проверь выход и повторный вход.
6. Если письмо не пришло, проверь, что в Supabase → Authentication → Emails → SMTP Settings включён Custom SMTP, параметры Resend сохранены, а шаблон Confirm sign up содержит {{ .Token }}. Также проверь папку «Спам».

ВАЖНО О ПОЧТЕ
-------------
Публичная функция уже опубликована, но настоящий сквозной сценарий нужно подтвердить тестовой регистрацией в браузере. Resend onboarding@resend.dev ограничивает получателей; чтобы отправлять коды произвольным игрокам, добавь и подтверди собственный домен в Resend и настрой Sender email на адрес этого домена.

КАК СОБРАТЬ WINDOWS EXE
-----------------------
1. Запусти build_exe.bat на компьютере с Windows 10/11.
2. Скрипт специально использует Python 3.12, чтобы не выбирать Python 3.15.
3. При первом запуске нужен интернет для установки PyWebView и PyInstaller.
4. После успешной сборки файл будет в dist\SkyRealm.exe.
5. Распространяй EXE только после успешной проверки регистрации и почты. Старый EXE не содержит эту обновлённую конфигурацию.

ЛОКАЛЬНЫЙ СЕРВЕР В ПАПКЕ server
------------------------------
Папка server оставлена как исходник старого локального FastAPI-варианта. Текущий лаунчер использует облачный Supabase API, поэтому локальный сервер для него не нужен. Локальная SQLite-база и аккаунты из старой версии не переносились в облако автоматически.

БЕЗОПАСНОСТЬ
------------
- Не добавляй API secret / service_role key, SMTP-пароль или файл .env в config.js, app.js, HTML или EXE.
- Публичный publishable key в config.js предназначен для клиентского приложения.
- Никому не отправляй секретный API-ключ Resend.
