SkyRealm v0.6.7 — исправление шахты, верстака, уведомлений и настроек мира

Исправления:
- Исправлена критическая ошибка запуска крафта печи, которая была причиной остановки игрового JavaScript в прошлой сборке.
- Шахта видна в долине, открывается клавишей E; внутри видны залежи камня, угля и железа. Выбери кирку в слоте 3 и нажми левой кнопкой мыши по залежи два раза.
- Верстак находится внутри дома: подойди и нажми E. В окне верстака можно создать печь за 8 камня и 6 древесины.
- Кнопка «Настройки мира» добавлена в меню паузы Esc. Изменение настройки монстров с первой ночи сохраняется для выбранного мира. После сохранения/закрытия настроек корректно возвращает в меню паузы.
- Уведомления перенесены в нижнюю часть экрана и больше не должны закрывать часы/табличку времени. Они находятся под модальными окнами.

Установка: распакуй архив в новую папку, открой SkyRealm_Auth_Project, запусти build_exe.bat и используй dist\SkyRealm.exe. Не запускай EXE из старой папки.

Проверки: node --check game/game.js, Python-компиляция launcher.py, проверка DOM ID и целостности ZIP. Запуск настоящего EXE в Windows в этой среде недоступен.
