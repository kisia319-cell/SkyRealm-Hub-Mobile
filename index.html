Частые вопросы

Как создать аккаунт?

На главной странице нажми «Создать аккаунт», введи имя игрока, электронную почту и пароль. Затем введи одноразовый код из письма.

Почему нужен код из почты?

Код подтверждает, что у тебя есть доступ к указанному адресу. Никому не сообщай этот код.

Как работает кнопка «Играть»?

При первом запуске лаунчер устанавливает лёгкие локальные файлы 2D-игры и открывает игру в отдельном окне.

Не пришло письмо с кодом

Проверь папки «Спам» и «Промоакции». Доставка для новых адресов может быть ограничена настройками почтового сервиса; в таком случае владелец проекта должен завершить проверку отправителя.
