SKYREALM HUB MOBILE — ПЕРВЫЙ ПРОТОТИП

Что уже подготовлено:
- Android-проект SkyRealm Hub, стартующий в альбомной ориентации.
- Главный экран-каталог 16:9: карточка SkyRealm и прозрачная карточка с плюсом для будущих игр.
- Кнопка «Играть» открывает существующий лаунчер SkyRealm из ПК-проекта (HTML-интерфейс).
- Внутренний лаунчер имеет Android-совместимый переход к game/index.html по кнопке «Играть».
- Кнопка Back на телефоне возвращает: игра -> лаунчер -> Hub.
- Встроена копия SkyRealm 0.9.2 из архива WEAPONS_ANVIL.

Как открыть:
1. Установи Android Studio.
2. Открой папку SkyRealm_Hub_Mobile_Project через File -> Open.
3. Дождись синхронизации Gradle и установки Android SDK 35 (если предложит).
4. Для APK: Build -> Build Bundle(s) / APK(s) -> Build APK(s).

Важно:
- Это исходный Android Studio проект, не готовый APK. В текущей среде Android SDK/Gradle не установлены, поэтому APK здесь не собирался.
- Это первый мобильный прототип. Серверные функции, облачная авторизация и сохранения требуют отдельной проверки на Android; настольный лаунчер изначально делался для Windows.
- Игра пока показывается в альбомном режиме. Управление на сенсорном экране может потребовать отдельной адаптации.


АВТОСБОРКА APK ЧЕРЕЗ GITHUB (без Android Studio):
1. Создай пустой репозиторий на https://github.com/new (например SkyRealm-Hub-Mobile).
2. Распакуй архив и загрузи ВСЕ файлы и папки проекта в репозиторий. Важно: папка .github тоже должна загрузиться.
3. Открой вкладку Actions в репозитории и разреши Actions, если GitHub попросит.
4. После первого push сборка запустится сама. Можно также открыть Actions -> Build SkyRealm Hub APK -> Run workflow.
5. Открой завершённый запуск (зелёная галочка), прокрути до Artifacts и скачай SkyRealm-Hub-APK.
6. Распакуй скачанный артефакт — внутри будет app-debug.apk. Перенеси его на телефон и установи.

Для загрузки проекта на GitHub не добавляй пароли или секретные ключи. Вкладка Actions собирает APK в облаке; APK не подписан для публикации в Google Play, это тестовая debug-сборка.
