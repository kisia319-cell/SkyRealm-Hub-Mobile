SkyRealm 0.5.0 — меню миров, админ-режим и исследуемая карта

Главное меню
- «Создать мир» открывает форму названия и сразу запускает новый мир.
- Существующие миры отображаются списком. Можно войти в выбранный мир или переименовать его.
- «Настройки» открывает текущие вкладки «Графика» и «Интерфейс».
- «Выйти из игры» закрывает окно игры.
- «В меню миров» доступно из паузы и позволяет выбрать другое сохранение.

Админ-режим
- Включи его в настройках лаунчера и затем заново запусти игру.
- После этого появится кнопка «Админ-панель» в главном меню.
- Пароль: тот, который задан для локального прототипа в game/game.js.
- Это не защищённая система для публичного релиза: любой пользователь с доступом к клиентским файлам может обойти проверку. Для реальной админ-панели понадобится серверная проверка.

Радар
- Исследованные клетки сохраняются в каждом мире отдельно.
- По мере движения открывается область вокруг игрока.
- Неизведанная местность и объекты на ней не отображаются до исследования.

Сборка
Запусти build_exe.bat. Скрипт сначала создаёт отдельный процесс для игры, затем собирает основной SkyRealm.exe с ресурсами.
