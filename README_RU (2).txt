SKYREALM LAUNCHER 0.5.0 — БЫСТРЫЙ СТАРТ
========================================

ЧТО НОВОГО В 0.5.0
- При запуске игры открывается главное меню, а не сразу игровой мир.
- Можно создать несколько локальных миров, выбирать мир для входа и менять название сохранения.
- Сохранение позиции, игрового времени, здоровья, количества пережитых ночей и изученной карты ведётся отдельно для каждого мира.
- Мини-карта использует «туман войны»: видны только изученные области и замеченные в них объекты.
- В настройках лаунчера появился переключатель «Режим администратора». Если он включён до запуска игры, в главном меню будет доступна кнопка админ-панели с вводом пароля.
- В игровом меню доступны «Создать мир», «Настройки», «Выйти из игры» и, при включённом режиме, «Админ-панель».
- В паузу добавлена кнопка возврата в меню миров.

СБОРКА ДЛЯ WINDOWS
1. Установи Python 3.12, если он ещё не установлен. При установке отметь Add python.exe to PATH.
2. Запусти build_exe.bat из этой папки.
3. Дождись BUILD SUCCESSFUL.
4. Готовый файл: dist\SkyRealm.exe.

ОБЛАЧНЫЙ АККАУНТ
Регистрация работает через облачный Supabase API, настроенный в config.js. Отправка реальных писем зависит от SMTP-провайдера и его ограничений. Для публичной рассылки потребуется подтвердить собственный домен отправителя.

ВАЖНО ПРО АДМИН-РЕЖИМ
В этой версии админ-панель является локальным прототипом. Пароль хранится в клиентской части игры, поэтому его можно извлечь из файлов приложения; это не безопасная серверная система администрирования. Не используй её для доступа к реальным пользовательским данным. Для настоящих админ-команд проверку нужно перенести на закрытый сервер.

МИРЫ И СОХРАНЕНИЯ
Сохранения хранятся локально в профиле WebView/браузера этого компьютера. Они не синхронизируются между разными компьютерами и не становятся облачными аккаунтами автоматически.
