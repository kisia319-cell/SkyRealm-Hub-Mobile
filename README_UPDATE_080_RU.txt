SKYREALM 0.8.0 — ИСПРАВЛЕНИЕ ЧЁРНОГО ЭКРАНА

Причина по скриншоту DevTools: JavaScript останавливался во время старта игры, потому что обработчик пытался назначиться элементу craft-iron-sword, которого не было в HTML. После этого не запускались setupWorld() и игровой цикл requestAnimationFrame(tick), поэтому HUD был виден, а игровой мир оставался чёрным.

Что исправлено:
- добавлены отсутствовавшие кнопки рецептов железного меча и кожаной брони в окно верстака;
- обработчики этих дополнительных кнопок сделаны безопасными, если элемент отсутствует;
- повышена версия игры до 0.8.0, чтобы лаунчер обновил установленную копию.

Установка: распакуйте архив в новую папку, пересоберите EXE при необходимости и запустите игру. Существующие сохранения находятся в LocalAppData\SkyRealm; не удаляйте эту папку.

Проверки в этой среде: синтаксис JavaScript, синтаксис Python и целостность ZIP. Windows runtime не запускался.
