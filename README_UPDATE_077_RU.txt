SkyRealm 0.7.7 — исправление чёрного экрана

Что изменено:
- Добавлен резервный рендерер игрового мира: если ошибка в отрисовке декораций возникает во время игры, игрок всё равно увидит землю, дорожки, воду и персонажа.
- Добавлена перерисовка canvas при изменении размера окна и масштаба экрана.
- Ошибки отрисовки теперь выводятся в консоль для дальнейшей диагностики.
- Сохранены функции строительства, печи, дополнительных домов и крафта из версии 0.7.6.

Проверено: синтаксис JavaScript, целостность ZIP. Полный запуск в Windows в этой среде не выполнялся.
