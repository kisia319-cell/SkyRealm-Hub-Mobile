SkyRealm v0.7.3 — исправления торгового мира

• Постоянный золотой баланс виден в игровом интерфейсе и обновляется после покупок/продаж.
• В Мире торговли теперь отдельная чистая площадка: обычный дом, деревья, камни и знаки основной долины не рисуются.
• На карте торгового мира нарисованы две заметные лавки: Лавка лесника и Лавка рудокопа; возле них отображаются подсказки для E.
• В торговом мире не остаются невидимые коллизии деревьев/дома.
• Переход между мирами сопровождается плавным затемнением и появлением из чёрного экрана; персонаж размещается у портала.

Проверки: синтаксис JavaScript и Python и целостность ZIP. Сам запуск в Windows не выполнялся.
