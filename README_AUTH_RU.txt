SKYREALM — АВТОРИЗАЦИЯ
=======================

Актуальные инструкции находятся в README_CLOUD_RU.txt.

Текущий лаунчер использует облачный Supabase API. Папка server содержит только локальный вариант разработки/резервные исходники и не требуется для работы лаунчера в облачном режиме.

Не добавляй SMTP-пароли или секретные API-ключи в файлы лаунчера и не включай их в EXE.
