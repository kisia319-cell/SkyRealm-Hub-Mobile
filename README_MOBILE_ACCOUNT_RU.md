# Аккаунт в мобильном SkyRealm Hub

В Android-приложении форма аккаунта открывается из пункта «Профиль» или из карточки локального профиля слева.

## Регистрация
1. Открой «Профиль» → «Регистрация».
2. Введи имя игрока (3–20 букв, цифр или подчёркиваний), электронную почту и пароль (8–128 символов).
3. Введи код подтверждения из письма. Код принимается в диапазоне 6–10 цифр; сервер отправляет шестизначный код.
4. После подтверждения Hub автоматически войдёт в аккаунт.

## Вход и сессия
- Войти можно по имени игрока или почте.
- Есть повторная отправка кода.
- После входа Hub показывает имя игрока и почту.
- Сессия обновляется через refresh token; пароль не сохраняется.
- Выход отзывает текущую сессию на сервере и очищает локальные токены.

Используется существующий публичный SkyRealm Auth API из `skyrealm/config.js`. Секретный service-role ключ и SMTP-пароли в приложение не включаются.
