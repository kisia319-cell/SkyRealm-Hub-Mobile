SkyRealm 0.7.8 — исправление остановки игрового кадра

В 0.7.7 резервный рендерер срабатывал при ошибке непосредственно в draw(), но исключение раньше по ходу кадра могло остановить requestAnimationFrame и оставить игровое поле чёрным.

В 0.7.8 добавлена общая защита всего игрового кадра: при исключении выводится подробная ошибка в консоль, запускается резервная отрисовка мира и цикл кадров продолжается.

Проверки: синтаксис JavaScript и целостность ZIP. Запуск в Windows в этой среде недоступен; исправление не считается подтверждённым до проверки у пользователя.
