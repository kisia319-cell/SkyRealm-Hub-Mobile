SkyRealm v0.6.0 — Admin & Moderator

Добавлено:
- Отдельный переключатель режима модератора в настройках лаунчера.
- Панель администратора с восстановлением здоровья, бессмертием, выдачей ресурсов, сменой времени, созданием/удалением монстров и картой.
- Панель модератора: здоровье, бессмертие, карта/телепорт, день/ночь, создание/удаление монстров и локальный список блокировки.
- Полная карта по клавише L. На ней показываются только исследованные клетки; телепорт доступен только в открытую область.
- Выданные ресурсы сохраняются в сохранении мира.

Важно для публичного релиза/Steam:
Эта сборка всё ещё локальный 2D-прототип. Пароль администратора проверяется в клиентском коде, а список блокировки хранится локально. Он НЕ блокирует настоящих сетевых игроков. Не публикуйте пароль как секрет и не используйте эти панели как защиту публичного сервера. Для реальных аккаунтов, банов, ролей и модерации нужен сервер, который проверяет права и сохраняет баны на серверной стороне.

Запуск из исходников: запустите launcher.py при установленных зависимостях из requirements/инструкций проекта. Сборка Windows: build_exe.bat.
